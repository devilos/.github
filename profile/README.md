Everything runs on the edge — Nuxt on Cloudflare Workers, D1 or Postgres behind
Drizzle, R2 for the heavy things. The extensions are cross&#8209;browser, Chrome and
Firefox from one codebase.

## Working here

Every repository in this organization shares one CI pipeline and one set of
branch rules, defined once in [`Devilos/.github`](https://github.com/Devilos/.github)
rather than copied into each project.
